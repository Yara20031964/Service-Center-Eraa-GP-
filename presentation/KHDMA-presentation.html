The Problem

Booking a local service is still slow, opaque and unsafe

Hard to find trusted help

Locating a reliable, nearby provider relies on word-of-mouth and phone calls.

No transparent pricing or history

No ratings, no booking record, no way to compare providers before hiring.

Cash-only, no safe payments

No secure transactions, no commission model, and no dispute handling.

Providers lack business tools

No way to manage jobs, availability, portfolio or track their earnings.

3disconnected sides — customers, providers & admins
0shared platform to book, pay and manage in one place
100%manual coordination today, with no accountability
KHDMA · Problem03 / 12
Our Solution

One platform that connects customers, providers and admins — book, match, pay and manage in real time.

KHDMA turns a fragmented, offline process into a single trusted marketplace with smart matching and secure payments.

Customers

Browse categories, book a service, chat, pay and leave a review.

Providers

Receive geo-matched job requests and run their business from one app.

Smart dispatch

The nearest available provider is matched automatically.

Secure payments

Built-in commission and automated provider payouts.

Admin oversight

The whole ecosystem is managed from one dashboard.

System Architecture

Clean Architecture — one API, three clients

Customer AppFlutter · Android & iOS
Provider AppFlutter · Android & iOS
Admin DashboardReact · TypeScript
APIASP.NET Core REST endpoints + SignalR real-time hub · JWT auth · Swagger
ApplicationCQRS use-cases with MediatR — commands, queries & business workflows
InfrastructureEF Core · SQL Server / MySQL · Redis · Azure Blob · Firebase messaging
DomainEntities & business rules — Bookings, Providers, Payments, Reviews…

Dependencies point inward — outer layers depend on the Domain, never the reverse.

For Discussion

Security, challenges & future work

Security
  • JWT access + refresh-token rotation
  • Role-based authorization per endpoint
  • Audit logs for sensitive actions
  • Secrets stored in GitHub, never in code
Challenges solved
  • Real-time sync across three clients
  • Accurate geo-matching of providers
  • Commission & payout calculation logic
  • Scalability via Redis backplane + stateless API
Future work
  • Integrated online payment gateway
  • AI-powered provider recommendations
  • Multi-language (Arabic / English)
  • Automated testing & monitoring
